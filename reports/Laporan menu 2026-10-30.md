## Tips main

1. Jalankan server seperti biasa (`http_config.py 443 --tls` + `messenger.py`).
2. **Beli pack**: Shop → Pak pemain → arahkan ke pack → Beli → Beli → "Cek item" → Gunakan → Buka 1 pak.
3. **Upgrade**: beli kartu kedua dari pemain yang sama di Market (atau dapat dari pack) → Tim → Manajemen pemain → Upgrade.
4. **Tukar**: pemain yang mau ditukar harus cadangan (di luar 18 skuad) → Tim → Manajemen pemain → Tukar → centang 2–10 → Tukar → "Konfirmasi semua" → pilih tawaran → konfirmasi.
5. **Tukar Scout**: Tim → Manajemen pemain → Skuad → klik **RES** hijau pada pemain cadangan (pindah ke Tim Cadangan) → tab Tukar kedua → pilih scout → centang pemain → Lanjutkan negosiasi → Konfirmasi semua → pilih → konfirmasi.
6. Liga/Cup: seperti sebelumnya (Single → Liga / Cup).
7. **Hadiah harian**: login → Item saya → Items → klik kartu → Terima (atau Terima semua).
8. **Admin**: browser → http://127.0.0.1:8088/ (server harus jalan). Perubahan langsung tersimpan; tampil di game setelah layar terkait dibuka ulang atau game dibuka ulang.

- `gamedata/fa_prices.json` (baru, harga fifaaddict), `tools/fa_sync.py` (baru, sinkron harga), `gen_teams.py` (skuad musim 2017), `gamedata/state.json` (dimigrasi ke kartu 2017).
- `responses/`: `static_db_STATICVALUES.json` (aturan Tukar + ambang efek kartu), `static_db_PLAYERGRADE.json` (boost grade), `account_base.json` (fitur VIP + trade3), `static_db_CLUBACTIVITYPOINTS.json`, roster tim; `shop_list.json` dihapus (diganti handler server).
- `test_league.py`: tes Upgrade, Tukar, Tukar Scout, pindah tim, Shop/pack, rating klien, hadiah harian + Bag, API admin (termasuk proteksi HTTP).
- Hadiah harian + Bag: `http_config.py` (`daily_login` saat login, `/bag`, `/bag/<id>/unpack`, `/bag/unpackall`, item EP di `/static/cache/item`); tabel di `gamedata/daily_rewards.json` (dibuat saat tabel disimpan dari admin; tanpa file = tabel bawaan).
- Grade 0 + Shop: `http_config.py` (`grade_of`/`card_price` +0, `SHOP_FREE`, `ITEMS`, `PACKAGES`, `MP_SHOP`, `CHAINED`, `SPECIAL`, `MONTHLY`, `/item/<id>/use` per tipe item, `/monthlypack`, `/specifictarget`, `/shop/list/STSHOP`, `/static/info/team/summary/<id>`), `responses/monthlypack.json` dipindah ke backup (diganti handler), `admin.py`/`admin/index.html` (grade 0), `test_league.py` (grade 0, semua tab Shop).
- Musim/pack/buat klub: `responses/static_roster.json` (`curseason` 17), `http_config.py` (50 `PACKS`, pool multi-musim + grade, `SORTNATION`/`SORTLEAGUE`/`SORTTEAM`, `/static/info/authentic/team/licensed|all/<id>`, `step/3` untuk klub mana pun), `gen_teams.py` (XI per rating posisi, `summary` id/ovr/teamgrade; 7 file tim awal dibuat ulang), `test_league.py` (mulai dari akun baru lewat alur buat klub; tes pack grade, picker klub).
- Hapus manager: `http_config.py` (`/coach/<slot>/postponed` hapus, `/coach/<id>/postponed` DELETE = kembalikan, `purge_deleted_coaches`, `/coaches` kirim `recoveryperiod` + `hideat`, `COACH_RECOVERY` = 300 detik).
- Lagu pembuka: `tools/eatrax_song.py` (baru), `tools/re/bigdir.py` (baru: baca/tulis tabel arsip BIg4), `tools/re/refpack.py` (kompresor RefPack), `music/starter.mp3`; arsip game `D:\FO3ID\32795\data\data_0.big` + `data_1.big` diubah (asli di `backup/eatrax/`); pemutar musik di server (versi pertama, bentrok dengan musik game) dihapus dari `http_config.py`.
- Login/lobby: `messenger.py` (signon cukup dijawab `sign`). Pilihan terbaik: `responses/static_db_STATICVALUES.json` (`best_squad`).
- Admin: `admin.py` + `admin/index.html` (baru); `http_config.py` menyalakannya di port 8088 (env `FO3_ADMIN_PORT`, `0` = mati) dan sekarang memakai satu kunci (`STATE_LOCK`) supaya game dan admin tidak saling menimpa `state.json`.
